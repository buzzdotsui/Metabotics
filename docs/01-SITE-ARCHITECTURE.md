# METABOTICS
# SITE ARCHITECTURE SPECIFICATION

Version: 1.0
Status: Foundation
Purpose: Master information architecture for the Metabotics public website.

---

# 01. CORE PRINCIPLE

Metabotics is not presented as a generic SaaS company.

The website represents:

    SOFTWARE FOR THE PHYSICAL WORLD.

The entire information architecture follows the transformation:

    PHYSICAL SYSTEM
          ↓
        DATA
          ↓
     DIGITAL TWIN
          ↓
     INTELLIGENCE
          ↓
     OPTIMIZATION

This sequence is the conceptual backbone of the website.

Every major page should reinforce at least one part of this system.

---

# 02. PRIMARY WEBSITE OBJECTIVE

The website must communicate five things quickly:

1. WHAT METABOTICS IS
2. WHAT INDUSTRIAL PROBLEM IT ADDRESSES
3. HOW THE TECHNOLOGY WORKS
4. WHERE THE TECHNOLOGY IS APPLIED
5. HOW A PERSON OR ORGANIZATION CAN WORK WITH METABOTICS

The website must not feel like:

- a generic AI startup
- a generic SaaS dashboard
- a portfolio website
- a marketing template
- a university project
- a collection of unrelated pages

It must feel like:

- an industrial technology company
- an engineering organization
- a software infrastructure company
- a research-driven technology platform
- an organization building intelligent systems for physical processes

The most important rule:

    DO NOT DESIGN A COLLECTION OF PAGES.

Design one coherent system.

The user should be able to move from:

    PHYSICAL SYSTEM

to:

    DATA

to:

    DIGITAL TWIN

to:

    INTELLIGENCE

to:
